# 🏥 Hospital Patient Data Analysis

## 📌 Project Overview

This is a beginner data analysis project developed using **Python**, **Pandas**, **NumPy**, and **Matplotlib**.

The project analyzes hospital patient data and creates visualizations to understand patient information and hospital billing.

## 🛠 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib

## 📊 Features

* Read hospital data from a CSV file
* Display dataset information
* Calculate average age and average bill
* Find maximum blood pressure and sugar level
* Find the patient with the highest bill
* Find the patient with the highest sugar level
* Group data by disease
* Filter diabetes patients
* Create Line Chart
* Create Bar Chart
* Create Pie Chart
* Create Histogram
* Create Scatter Plot

## 📁 Project Files

* `mini_project.py` – Main Python program
* `hospital.csv` – Dataset
* `README.md` – Project documentation

## ▶️ How to Run

1. Download or clone the project.
2. Make sure Python is installed.
3. Install the required libraries:

   ```
   pip install pandas numpy matplotlib
   ```
4. Run the program:

   ```
   python analysis.py
   ```

## 📈 Output

The project generates:

* Line Chart
* Bar Chart
* Pie Chart
* Histogram
* Scatter Plot
